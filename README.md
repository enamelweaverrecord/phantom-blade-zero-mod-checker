## Quick diagnosis: what failed?

| Symptom | What to check first |
| --- | --- |
| UE4SS mods do not load at all | Confirm the correct `PBZ.exe` folder and look for `UE4SS.log`. Search for `GNatives`, `GUObjectArray`, and initialization errors. |
| The game reaches a broken menu after an update | Look for older PAK files that replace game scripts. Check the affected mod's update instructions. |
| One newly installed mod causes a crash | Remove that mod temporarily, test without it, then reintroduce mods one at a time. |
| Lua mod installed but its effects are missing | Confirm `ue4ss\Mods\<ModName>\` exists and review the mod's enablement requirements. |
| UE4SS works, but a menu mod does not | Check whether the mod requires **Mods Menu**, **PBZModLoader**, or a separate bridge rather than UE4SS alone. |
| There is no `UE4SS.log` | Recheck the loader location and the installation instructions of the specific UE4SS package. |

An error in one loader does not mean every mod is broken. Check which loader a particular mod actually requires before changing its files.

## Find the right Phantom Blade Zero directory

1. Open **Steam → Library**.
2. Right-click **Phantom Blade Zero** → **Manage** → **Browse local files**.
3. The game root normally contains `ProjectPBZ` and `platform`.
4. For UE4SS installations documented on Nexus Mods, locate the executable under `platform\steam` and read your specific UE4SS package's instructions. If the folder layout differs, use the paths required by your installed version.

Typical **Steam/Windows** layout:

```text
steamapps/
└── common/
    └── PBZ/                         <- game root
        ├── platform/
        │   └── steam/
        │       ├── PBZ.exe
        │       ├── dwmapi.dll        <- used by certain UE4SS builds
        │       └── ue4ss/
        │           ├── UE4SS.log
        │           ├── mods.txt      <- if included by your UE4SS package
        │           └── Mods/
        │               └── ExampleMod/
        └── ProjectPBZ/
            └── Content/
                └── Paks/
                    └── ~mods/        <- PAK mods, when the mod author specifies it
```

`ExampleMod` is a folder name for illustration only. Don't create empty folders or copy unrelated DLL files just to match the diagram. Mod managers and different packages can use different locations.

## UE4SS not working after the November 4 patch

The November 4, 2026 update, described in mod community posts as **patch 1.0302256**, caused compatibility problems for certain UE4SS builds. A common log symptom is:

```text
Was unable to find AOB for 'GNatives'
Was unable to find AOB for 'GUObjectArray'
```

If you see those messages, the issue may be the **installed UE4SS build or its signatures**, not the Lua mod itself.

1. **Close the game.** Do not overwrite files while PBZ is running.
2. **Locate the log:** check `PBZ\platform\steam\ue4ss\UE4SS.log` for the UE4SS package you installed. Copy the log elsewhere before restarting the game, since logs can be overwritten.
3. **Identify your UE4SS package.** Different packages have different files and update procedures. For example, the *UE4SS for Phantom Blade Zero* package and *OFFICIAL UE4SS for PBZ* are distinct Nexus Mods downloads.
4. **Check the author page for your exact package and game build.** Use its current installation/update instructions. Do not combine DLLs and signatures from unrelated packages.
5. **Preserve your mods and settings**, including your `Mods` folder and `mods.txt` where applicable, before any reinstall.
6. **Test UE4SS by itself** before adding other mods back. When it starts correctly, re-enable or restore mods individually.

The community has published a specific **UE4SS Patch Fix** for the `GNatives` / `GUObjectArray` problem, but its author states it is intended for a particular UE4SS package. Don't treat that fix as universal.

## Fix PAK mods that stopped working after a game update

Some older PAK mods replaced game scripts. The November 4 update changed how those scripts were loaded, so certain older versions no longer work correctly. **Not every PAK mod is affected**—texture or data mods and script-replacement mods are not interchangeable.

1. Open the game root in Steam and navigate to `ProjectPBZ\Content\Paks\~mods` **if your mod author uses that location**.
2. Make a backup of the files you installed. Keep `.pak`, `.utoc`, and `.ucas` files together when they belong to the same mod.
3. Check the mod page for a **November 4 compatible version** and any required loader.
4. Temporarily move **only the affected mod's files** out of `~mods`, into a backup directory outside the game folder.
5. Start the game with the affected mod removed. If the main menu works again, follow that mod's current install instructions instead of restoring the broken version.
6. Add other mods back one by one until you find the conflict.

A documented example is **Map Collectible Markers**: its author provided migration steps from older PAK variants to either a UE4SS version or newer loader-based versions. If you use this mod, follow the **version-specific** instructions on its page rather than removing all PAK files.

[Map Collectible Markers — mod author instructions](https://www.nexusmods.com/phantombladezero/mods/134)

## Back up your mod setup before troubleshooting

Keep a dated copy of the relevant files **outside** the PBZ installation directory, for example in a folder under Documents. You can back up:

- `platform\steam\ue4ss\Mods` and `mods.txt`, when they exist;
- your UE4SS configuration and loader-specific settings;
- the mod files you placed under `ProjectPBZ\Content\Paks\~mods`;
- a text note listing installed mod versions and download links.

Avoid mixing two different UE4SS packages in the same installation. If a tool offers a restore option, check what it will overwrite first. A mod backup does **not** replace a separate game-save backup.

## Still having trouble? Collect these details

If the game or loader still fails, note the following before opening a GitHub Issue or asking the mod author:

- Your game storefront (**Steam** or another edition) and game build / last update date.
- Your Windows version and the name/version of the installed UE4SS or mod-loader package.
- Whether the game starts without mods.
- Whether `UE4SS.log` is created and the **exact** first error shown.
- Which mod was installed immediately before the problem started.
- Whether the problem is a crash, a frozen main menu, a missing mod setting, or a Lua script that does not run.

Remove usernames and other personal paths from screenshots or logs before sharing them publicly. If you suspect a corrupt base installation, use **Steam → Properties → Installed Files → Verify integrity of game files** after making a backup of your mod setup. Verification may replace modified game files.

## FAQ

**Why are my Phantom Blade Zero mods not working after an update?**  
Some mods rely on an exact game build, UE4SS version, or loader. The November 4 patch is a documented example: older UE4SS signatures and some script-replacement PAK mods needed updates.

**Does a UE4SS patch fix every Phantom Blade Zero mod?**  
No. A UE4SS startup fix is not the same thing as a fix for incompatible PAK scripts or for a mod that requires Mods Menu.

**Where do Phantom Blade Zero UE4SS mods go?**  
For the documented Steam/Windows packages, the usual location is `PBZ\platform\steam\ue4ss\Mods`. Check the specific mod's installation instructions.

**Where should Phantom Blade Zero PAK mods go?**  
Many are installed under `PBZ\ProjectPBZ\Content\Paks\~mods`, but the mod author determines the correct directory and whether a loader is required.

**Will this help with Phantom Blade Zero FPS drops?**  
This project focuses on **mod compatibility and loader troubleshooting**, not graphics tuning or general FPS optimization. A game that runs normally without mods may have a mod-related problem, but not every stutter is caused by mods.

**Does this apply to PS5, Steam Deck, or Linux?**  
The paths and troubleshooting flow here target **Windows + Steam**. Other platforms may have different layouts and loader requirements.
